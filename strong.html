Etiqueta Strong <strong>

Se utiliza para indicar que el texto es importante. Es decir, se utiliza para marcar un texto como importante dentro de un contenido (lo pone en negrita). Es una etiqueta en línea, lo que significa que el texto es parte de una línea de contenido. Aqui dejo un ejemplo de su uso:

<strong> Este texto es importante </strong>
