Etiqueta Em <em>

Se utiliza para indicar que el texto es enfatizado. Es decir, se utiliza para marcar un texto como enfatizado dentro de un contenido (lo pone en cursiva). Es una etiqueta en línea, lo que significa que el texto es parte de una línea de contenido. Aqui dejo un ejemplo de su uso:

<em> Este texto está enfatizado </em>
