Ejercicio N° 5.1 HTML

HTML Son las siglas de Hypertext Markup Language, que puede traducirse como "Lenguaje de Marcas o marcado de Hipertexto".

El lenguaje HTML se emplea para crear páginas web. Es muy facil ver el código HTML de una página web, la opción exacta
cambia de un navegador a otro y también de una versión a otra de un mismo navegador, pero suelen tener un nombre similar.

HTML se compone de etiquetas que se escriben entre los simbolos menor que y mayor que.

Historia de HTML

Los inicios del lenguaje HTML se remontan a los años 90, cuando Tim Berners-Lee desarrolló el lenguaje como parte del proyecto
World Wide Web.

Versiones de HTML

Tim Berners-Lee definió la primera versión de HTML en el año 1991.

En la actualidad, la ultima versión de HTML es HTML5
