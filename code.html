<code>

Se utiliza para indicar que el texto es un fragmento de código. Es decir, se utiliza para marcar un fragmento de código dentro de un texto. Es una etiqueta en línea, lo que significa que el texto es parte de una línea de contenido. Aqui dejo un ejemplo de su uso:

<code> console.log("Hola mundo"); </code>
